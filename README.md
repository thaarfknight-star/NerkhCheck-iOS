# NerkhCheck — نسخه‌ی iOS

اپلیکیشن نیتیو iOS برای مشاهده‌ی لحظه‌ای قیمت ارز، طلا، سکه و ارز دیجیتال — نوشته‌شده با SwiftUI.

## امکانات

- 📊 قیمت لحظه‌ای ۲۱ نماد: ارزها (دلار، یورو، پوند، ...)، طلا (۱۸/۲۴ عیار، مثقال)، سکه و **ارز دیجیتال** (بیت‌کوین، اتریوم، تتر)
- 🌐 قیمت‌گذاری چندمنبعی کامل: ۶ منبع موازی با اولویت منابع داخلی (سرور ایران)؛
  نوبیتکس (بدون کلید) و کوین‌گکو برای رمزارزها
- 🔑 کلید BRS (اختیاری): با ثبت کلید رایگان BRS در تنظیمات، دلار و همه‌ی ارزها هم روی اینترنت ملی زنده می‌شوند
- 💾 کش هوشمند: آخرین قیمت‌های موفق ذخیره می‌شوند؛ وقتی منبعی در دسترس نیست، قیمت ذخیره‌شده با برچسب «ذخیره‌شده» نمایش داده می‌شود
- 🔄 تبدیل ارز بین همه‌ی نمادها (شامل رمزارزها) و تومان
- 🎨 شش تم رنگی ترکیب‌شده (شفق قطبی، آتشفشان، کهکشان، ساحل، جنگل، نئون)
- 🧩 ویجت هوم‌اسکرین: دلار، طلای ۱۸ عیار و سکه امامی با دکمه‌ی تازه‌سازی
- 🌙 حالت تیره، رابط کاملاً فارسی و راست‌به‌چپ

## منبع داده

دریافت از چند منبع به‌صورت موازی، با ادغام بر اساس اولویت (برای هر نماد، اولین منبع موفق؛ منابع داخلی اول):

۱. **BRS API** — سرور ایران، ارز و طلا؛ فقط وقتی کلید در تنظیمات ثبت شده باشد
۲. **نوبیتکس** — سرور ایران، ارز دیجیتال (بیت‌کوین، اتریوم، تتر)، بدون نیاز به کلید
۳. **tala.ir** — سرور ایران، طلا و بخشی از سکه‌ها، بدون نیاز به کلید (با اعتبارسنجی مقادیر)
۴. **صفحه‌ی اصلی TGJU** — هاست خارجی، همه‌ی نمادها + بیت‌کوین و تترِ زنده
۵. **وب‌سرویس اسنیپت TGJU** — هاست خارجی، جایگزین نهایی (ارز و طلا و سکه)
۶. **کوین‌گکو** — هاست خارجی، بدون نیاز به کلید؛ فقط برای کریپتوهای جامانده، با تبدیل دلار به تومان

اگر هیچ منبعی در دسترس نباشد، آخرین قیمت‌های موفقِ ذخیره‌شده (حداکثر ۷ روز)
با برچسب «ذخیره‌شده» نمایش داده می‌شوند.

## ساخت

```bash
xcodebuild -scheme NerkhCheck \
  -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPhone 16' build
```

- Display Name: ‏NerkhCheck
- نسخه: 1.1.0 (Build 5)
- Bundle ID: ‏com.chandeh.app
- نیازمند iOS 17 به بالا و Xcode 16

## App Group

اشتراک تم فعال، کلید BRS و کش قیمت‌ها بین اپ و ویجت از طریق App Group انجام می‌شود:

```
group.com.chandeh.app
```

این شناسه باید در تنظیمات Signing هر دو تارگت (اپ و ویجت) فعال باشد.
